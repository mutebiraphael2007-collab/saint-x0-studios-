# Saint_X.0 Studios — Official Website

A responsive, single-page publishing headquarters for Saint_X.0 Studios.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `saint-x0-studios`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root (not inside another folder).
3. Open the repository's **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The expected address is:
   `https://YOUR-GITHUB-USERNAME.github.io/saint-x0-studios/`

## Current content status
The website intentionally shows an empty story library and says the catalogue is in development. No fictional titles, fake reviews, fake reader counts, or non-working social links are included.

## Editing
Edit the text in `index.html`. Adjust colours and layout in `styles.css`.
